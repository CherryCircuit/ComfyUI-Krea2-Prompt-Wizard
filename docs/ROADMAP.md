# Release roadmap

## Visual strength previews

For the final release, concept sliders should be able to show small,
pre-rendered reference images while the pointer moves across the control.
The reference set should use a consistent subject and demonstrate each
quarter-step where that is useful. Lighting, camera, lens, colour, and style
concepts are the highest-value starting categories.

The image library should be optional, cached with the node, and lazy-loaded so
the normal editor stays fast. Each thumbnail must identify the model and
generation recipe used to create it so the visual guidance remains honest.
